# Unity Arcade / Casual Game 

Bu proje, Karabük Üniversitesi Oyun Geliştirme ve Programlama bölümünde geliştirilen bir **Unity Arcade / Casual Game prototipi**dir. Amacımız temel oyun mekaniklerini uygulayarak pratik kazanmak ve oyun geliştirme sürecini öğrenmektir.

## Features

- Player movement system (WASD)
- Sprint mechanic (Shift ile koşma)
- Camera control (Mouse look)
- FPS counter UI
- Animator integration (Character animations)

## Technologies

- Unity
- C#
- TextMeshPro
- AI

## Purpose

Bu proje ile:

- Unity’de temel oyun mekaniklerini uygulamak  
- Karakter hareketi, animasyon ve UI sistemlerini öğrenmek  
- GitHub ve LinkedIn’de portföy oluşturmak  

amaçlanmıştır.
