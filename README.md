# Unity Arcade / Casual Game 

Bu proje, tek başıma geliştirdiğim bir Unity Arcade / Casual Game prototipidir. Amacım fizik tabanlı mobil oyun mekaniklerini uygulamak, oyun kontrollerini ve kullanıcı arayüzünü tasarlayarak oyun geliştirme becerilerimi geliştirmektir.

## Features

- Player movement system (Joystick)
- Sprint mechanic (Dash Button)
- Camera control (Follow Camera/Cinemachine)
- FPS counter UI
- Animator integration (Character animations)

## Technologies

- Unity
- C#
- TextMeshPro
- AI

## Purpose

Bu proje ile:

- Unity’de temel oyun mekaniklerini uygulamak  
- Karakter hareketi, animasyon ve UI sistemlerini öğrenmek  
- GitHub ve LinkedIn’de portföy oluşturmak  

amaçlanmıştır.
